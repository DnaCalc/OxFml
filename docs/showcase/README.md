# OxFml Showcase Brochure

Open `index.html` directly in a web browser.

The document is a 20-page, print-friendly technical showcase covering:

1. OxFml ownership and repo modules,
2. source, syntax, red projection, binding, semantic planning, evaluation, publication, and FEC/F3E flow,
3. key data structures and code snippets,
4. OxFunc boundary rules,
5. W075 evaluator optimization floor and current fixture timings,
6. future work attachment points.

For a PDF handout, open `index.html` and use the browser's print-to-PDF command.
